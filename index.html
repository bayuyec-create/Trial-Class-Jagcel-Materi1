# Apa Itu Fungsi (Formula) di Excel?

Bayangkan Excel sebagai koki. Fungsi (formula) adalah resep yang Anda berikan padanya. Secara sederhana, Fungsi adalah perintah siap pakai untuk melakukan perhitungan atau tugas tertentu.

Struktur Dasar Sebuah Fungsi

=
NAMA_FUNGSI
(
Argumen1; Argumen2...
)
=

"Sama dengan (Perintah dimulai!)"

NAMA_FUNGSI

"Nama Resepnya."

( )

"Wadah Bahan."

Argumen

"Bahan-bahannya."

;

"Pemisah Argumen" ( ; bisa juga , )

🔬 Anatomi Sebuah Fungsi

Mari kita bedah fungsi `=XLOOKUP(A2;$F$2:$F$10;$G$2:$G$10)` sebagai contoh.

=
XLOOKUP
(
A2
;
$F$2:$F$10
;
$G$2:$G$10
)
=

1. Tanda Sama Dengan

WAJIB diawali dengan tanda ini untuk memberitahu Excel bahwa Anda akan memulai perhitungan/fungsi.

XLOOKUP

2. Nama Fungsi

Ini adalah "kata perintah" spesifik seperti 'IF', 'SUM', atau 'AVERAGE'.

( )

3. Tanda Kurung

"Wadah" yang membungkus semua argumen. Wajib ada, bahkan jika fungsinya tidak butuh argumen.

$F$2:$F$10

4. Argumen

"Bahan baku" atau input. Bisa argumen, sel (A2) atau rentang sel (A1:A10), bedanya sel sama rentang adalah adanya ( : ).

;

5. Pemisah

Tanda ( ; atau ,) yang memisahkan satu "argumen" dengan yang lain.

# Apa Itu Fungsi "LOOKUP"?

Pada dasarnya, ini adalah alat untuk menemukan sesuatu. Bayangkan Anda memiliki buku telepon. Anda ingin mencari "Budi" (nilai dicari) di daftar nama (kolom pencarian) untuk mendapatkan nomor teleponnya (nilai kembalian).

Cari:
"Budi"
→
↓
Nama
Telepon
Ana
555-1234
Budi
555-5678
Caca
555-9012
→
↓
Hasil:
"555-5678"

Itulah tugas utama fungsi LOOKUP. Yang paling umum adalah VLOOKUP.

# Perbandingan 4 Fungsi Pencarian Utama

`VLOOKUP` adalah yang klasik, `XLOOKUP` adalah masa depan. Grafik ini membandingkan fleksibilitas dan kemudahan penggunaan (skala 1-10).

Kelemahan Klasik: VLOOKUP

Mencari data di kolom pertama dan mengambil data di sebelah kanannya. Ia tidak bisa "melihat ke kiri".

A (ID)
B (Produk)
C (Harga)
101
Apel
5000
102
Jeruk
7000

✅ Cari 'Jeruk' (B), ambil Harga (C)

=VLOOKUP("Jeruk", B:C, 2, FALSE) ➡️ 7000

❌ Cari 'Jeruk' (B), ambil ID (A)

=VLOOKUP(...) ⬅️ GAGAL! (#N/A)

Kekuatan Modern: XLOOKUP

Jauh lebih fleksibel. Anda memberinya kolom pencarian dan kolom hasil secara terpisah.

A (ID)
B (Produk)
C (Harga)
101
Apel
5000
102
Jeruk
7000

✅ Cari 'Jeruk' (B), ambil Harga (C)

=XLOOKUP("Jeruk", B:B, C:C) ➡️ 7000

✅ Cari 'Jeruk' (B), ambil ID (A)

=XLOOKUP("Jeruk", B:B, A:A) ⬅️ 102

Bentuk - Bentuk Tabel

Tabel Vertikal (untuk VLOOKUP)

Data diatur dalam kolom. Anda mencari ke bawah di kolom pertama.

A (ID) B (Produk) C (Harga)
101 Apel 5000
102 Jeruk 7000

Tabel Horizontal (untuk HLOOKUP)

Data diatur dalam baris. Anda mencari ke kanan di baris pertama.

ID 101 102
Produk Apel Jeruk
Harga 5000 7000

Tabel Gabungan

Data diatur dalam baris dan kolom (matriks). Anda perlu mencari ke bawah (baris) DAN ke kanan (kolom) untuk menemukan nilai.

Ukuran S Ukuran M Ukuran L
Baju 100.000 110.000 120.000
Jaket 250.000 260.000 270.000
Celana 150.000 160.000 170.000

Contoh: Mencari harga "Jaket" ukuran "M". Ini butuh 2 kriteria (baris & kolom). Rumus klasiknya adalah INDEX(MATCH, MATCH).

Solusi "Gabungan" (XLOOKUP)

Inilah keajaibannya. XLOOKUP tidak peduli dengan bentuk tabel. Ia menggantikan VLOOKUP (Vertikal) dan HLOOKUP (Horizontal) sekaligus. Untuk tabel 2D, XLOOKUP juga bisa dipakai secara bersarang (*nested*) untuk menggantikan INDEX(MATCH, MATCH).

# XLOOKUP (Pencarian Modern)

Microsoft akhirnya membuat satu fungsi super yang menyelesaikan SEMUA masalah ini. XLOOKUP adalah pengganti modern untuk VLOOKUP, HLOOKUP, dan bahkan INDEX(MATCH).
